
# SupportAI

AI-Powered Customer Support SaaS Platform

## Overview

SupportAI is a multi-tenant customer support
platform that combines traditional ticket management,
real-time communication, AI-assisted workflows,
and knowledge-base-powered responses.

## Technology Stack

- Next.js
- TypeScript
- NestJS
- PostgreSQL
- Prisma
- Redis
- BullMQ
- Socket.IO
- OpenAI API
- pgvector
- Docker
- Kubernetes

## Architecture

The initial application follows a modular monolith
architecture with separate frontend, API, and
background worker applications.

## Documentation

See the `/docs` directory for product requirements,
